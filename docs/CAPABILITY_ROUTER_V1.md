# AION ICLI Capability Router V1

## Purpose

Capability Router V1 wires AION's public-safe capability surface into the interactive prompt.

It makes AION ICLI more than a shell by exposing named modes:

- capabilities
- preflight
- creative
- intuition
- cortex
- connectors
- receipts
- verify
- next

## Why this exists

Interactive Mode V1 proved the persistent session.

Capability Router V1 wires the first visible capability layer into that session.

## Public-safe capability rule

Every capability remains:

- local-first
- no network by default
- no mutation by default
- no execution by default
- receipt-backed
- public-safe

## Capability meanings

### Preflight

Reviews an intended action before execution.

### Creative

Generates safe options, designs, names, UX, docs, and implementation directions.

### Intuition

Surfaces hidden assumptions, uncertainty, risk signals, and missing evidence.

### Cortex

Summarizes repo-visible public state from docs, reports, release metadata, and receipts.

### Connectors

Explains safe connector, API, model, and SDK request-envelope patterns.

### Receipts

Explains and locates local proof records.

### Verify

Explains how to run local proof/verifier scripts.

### Next

Recommends the next safe build step.
