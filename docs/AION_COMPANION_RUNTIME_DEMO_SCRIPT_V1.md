# AION Companion Runtime Demo Script V1

## Demo Thesis
AION is the trust layer that helps humans delegate autonomy safely without surrendering control.

## Recording Flow
1. Trading agent
   - Prompt: `protect my trading agent overnight`
   - Focus: capital protection, interruption boundaries, controlled delegation
2. Home/robot agent
   - Prompt: `protect my house while I am away`
   - Focus: family safety, forbidden actions, human confirmation gates
3. Shopping agent
   - Prompt: `help me delegate grocery buying without breaking my rules`
   - Focus: budget, allergy, substitution constraints, unauthorized purchase prevention
4. Coding agent
   - Prompt: `help my coding agent ship without breaking production`
   - Focus: verifier requirement, rollback path, sandbox-first proof
5. Mirror
   - Prompt: `mirror what I am really trying to build`
   - Focus: hidden thesis reflection, continuity, next best question

## What to Emphasize On Screen
- AION responds as protective companion first.
- Governance exists but stays in backend trace.
- Every response keeps safe delegation and one critical clarifying question.
