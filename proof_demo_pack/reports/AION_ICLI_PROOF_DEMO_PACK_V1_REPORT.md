# AION ICLI PROOF DEMO PACK V1

## Thesis

Most AI tools generate claims.

AION ICLI checks whether a claim is admissible.

---

## Why This Is Useful

AION ICLI operates as a local-first governance and proof layer.

Instead of automatically trusting outputs,
AION asks for:

- artifacts
- receipts
- verifier markers
- release lineage
- proof chains

---

## Example

User:
Should I run this script?

AION:
I inspected the artifact locally.
It contains network and mutation indicators,
but no rollback or dry-run controls.

Decision:
REVIEW_ONLY

Proof:
LOCAL_ONLY · NO_EXECUTION · RECEIPT_WRITTEN
